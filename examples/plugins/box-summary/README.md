# 框选合计

在地图上框一片地方，它按你正在看的那一年合计：

- 陆地有多大
- 有几个州（治所在框里的州）、一共多少人
- 10 万人以上的城市有几座
- 这些州各归哪国，各占多少

拖时间轴换一年，它跟着重算。点「存成标记」，它把框住的州圈成一个标记，合计写在标记的说明里；这个标记和你自己加的一样，能在「标记」里改、删，也能撤销。不点就什么都不改。

在地图右下的「工具」里打开。

用到的能力：

- 看地图：算框里陆地的面积
- 看历史：数框里的州、人口、城市，看各州归哪国
- 知道你在看哪一年、框了哪里：按那一年合计，请你在地图上框一片
- 会改你写的东西：只在你点「存成标记」时加一个标记

这是「文明与地图」插件开发文档里的示例，MIT 许可证，可以拷去改成自己的插件。
