# 魔力

推演插件：给世界加一样新东西，魔力。

- 一开始，约十六分之一的州底下有灵脉，各有强有弱
- 魔力从灵脉涌出，向邻州慢慢漫开，自己也会慢慢散掉；人多的地方魔力被耗得快
- 魔力浓的州，城的人口上限高：魔力满 100 时上限翻一倍。新建世界时可以拨「魔力对城的影响」，0 是不影响，拨到 3 时魔力满 100 的州上限是原来的四倍
- 魔力浓度存成图层，每 50 年一份，看得出它怎么涨落

魔力怎么涨落是清单里的几条公式，由网站来算；插件代码只把魔力浓度换成城的人口上限。只影响用它新推的世界，已经推好的世界不变；存下的图层跟着世界走，没装插件也看得到。

用到的能力：

- 在推演里加自己的数和事件、写编年史：每 5 年出手一次；自己的两张表（灵脉、魔力），接官方的乡村人口；把魔力存成图层
- 会改推演怎么走：交城的人口上限（按州）

这是「文明与地图」插件开发文档里的示例，MIT 许可证，可以拷去改成自己的插件。
