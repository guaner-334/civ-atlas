# 宗教生效

推演插件：信仰真的起作用。

- 一州信的和本国国教不同，本国更动荡（异教加得多，同一大教的别派加一半），这州也更难被同化；信同一个教的州同化得快一点
- 邻国大多信异教的国家更容易开战，邻国全同教的更不容易
- 大教的圣城落在接壤的异教国手里，奉这个教的邻国每 5 年有两成的机会兴兵去夺（为同一座圣城打过一次，隔 40 年才再打）
- 两个同教的小国都挨着同一个更强的异教国，每 5 年有一成半的机会结盟 40 年，一起对付它
- 兴兵、结盟都在编年史里记一句

新建世界时装上它，推出来的历史里，异教国家之间的仗多了，同教的盟约多了。只影响用它新推的世界，已经推好的世界不变。

用到的能力：

- 在推演里加自己的数和事件、写编年史：看各州信什么、各国的国教、谁和谁接壤、圣城在哪；每 5 年出手一次；在小本子里记着为哪座圣城打过、结的盟到哪年；写编年史
- 会改推演怎么走：交动荡（按州）、同化快慢（按州）、宣战的几率（按国）；下「宣战」「结盟」的命令
