# 厌战

推演插件：有议会的国家打仗没那么随便了。

- 设了议事会、议会的王国和共和国，开战要先过议会：宣战的几率打四五折
- 这样的国家打出去的仗，连着 4 年没打下一州，或者打满 8 年，议会厌战，遣使和对方立约罢兵 10 年，编年史里记一句「某国伐某国久攻不下，议会厌战，遣使议和」
- 打自己分出去的国（平叛、收复）不算；军政府不算

新建世界时装上它，推出来的历史里，有议会的国家打的仗少了、打得短了。只影响用它新推的世界，已经推好的世界不变。

用到的能力：

- 在推演里加自己的数和事件、写编年史：看各国的政体和议会，听宣战、攻占、议和；每年出手一次；在小本子里记着在打的仗；写编年史
- 会改推演怎么走：交宣战的几率（按国）；下「立约（议和、罢兵）」的命令
