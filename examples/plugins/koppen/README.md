# 柯本气候

地图插件：加一点季风，再画一张柯本气候分类图。

- 季风：纬度 10°–35°、离海不远、偏大陆东岸的陆地，全年降水多两成，夏天的雨更集中。雨多了，河和森林跟着变
- 分类图：估出每块陆地 12 个月的气温和降水，照柯本 - 盖格分类分成 30 类（热带雨林 Af、地中海式 Csa、亚寒带针叶林 Dfc……），画成一张图层；海和湖不画
- 新建世界时可以拨「季风强弱」（0–2，默认 1）：0 是不加季风，只画分类图

图层跟着地图存进世界，别人没装插件也看得到。

用到的能力：

- 会改地图：改降水
- 在地图上加图层：交每块陆地是哪一类，由网站来画

这是「文明与地图」插件开发文档里的示例，MIT 许可证，可以拷去改成自己的插件。
