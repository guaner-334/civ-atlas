# 雨影与极地

地图插件：高山背风那一侧少下雨；北极、南极可以改成海或陆地。

新建世界时可以拨四个滑条：

- **雨影**（0–3，默认 1）：每块陆地顺着风往上风找 500 公里以内最高的山，山比这块地高得越多，这块地的雨打折越多：高出 1500 米以上打满，滑条 1 时少四成，2 时剩不到四成，3 时剩两成多；风吹上坡的迎风坡多下一点（滑条 1 时最多多一成）。雨少了，背风那一侧多出草原和荒漠，河也少几条。拨到 0 是不改降水。网站本来就算了山挡雨，这个滑条是在那上面再加一层
- **北极**（−1–1，默认 0）：纬度高过「极区从几度起」的那一片，正数改成陆地、负数改成海。拨到 1 整片都是陆地，−1 整片都是海；拨到 0.5 只改离北极点近的那一半（极区从 70° 起时，就是 80° 以北）。0 是不动
- **南极**（−1–1，默认 0）：同上，南边
- **极区从几度起**（60–80，默认 70）：北极、南极两个滑条管多大一片

做不到的：

- 改成陆地的一律 200 米高，改成海的一律 −2000 米深。新陆地没经过雨水冲刷，看着比别处平，也没有山；原来的海岛被新陆地围住，岛上的低地可能积水成湖
- 雨影只看风从哪边来、上风有多高的山，不看山有多宽；风向是全年平均的盛行风，季风换向时背风的一侧不跟着换

用到的能力：

- 会改地图：改海拔、海陆，改降水
