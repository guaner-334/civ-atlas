# 量路程

在地图上点起点和终点，它沿陆路找最省时的一条路，算出要走多少公里、多少天，把路线画在地图上。

- 平地每天走 30 公里（骑马 60 公里），丘陵慢一半，山地要多花一倍半的工夫
- 海和湖上过不去；两个地方隔着水就说走不过去
- 量完一条接着等你点下一条，换一条路；不想量了，点顶上那条的「退出」（或按 Esc），路线留着
- 面板上能换走法、换个起点、清掉路线

在地图右下的「工具」里打开。算出来的路线只在用它的时候显示，关掉就没了，世界一个字不变。

用到的能力：

- 看地图：按地形和水陆找路、量距离
- 知道你点了哪里：请你在地图上点起点和终点
- 在地图上加图层和标注：画出路线
- 看历史（可选）：用附近的城给起点、终点起名字；不给也能用，改写经纬度

这是「文明与地图」插件开发文档里的示例，MIT 许可证，可以拷去改成自己的插件。
