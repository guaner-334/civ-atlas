# 量路程

在地图上点起点和终点，它按地形找最省时的一条路，算出要走多少公里、多少天，列出沿路经过的城，把路线画在地图上。

- 平地每天走 30 公里（骑马 60 公里），丘陵慢一半，山地要多花一倍半的工夫
- 步行、骑马只走陆路；两个地方隔着水就说走不过去，这时可以换成坐船再算
- 坐船：海上、湖上每天 120 公里；只能在挨着水的陆地上船、下船，上一次、下一次各多算一天；起点、终点在内陆的，先走陆路到岸边（陆上照步行算）。结冰的海上过不去，船绕开走；绕不过去就说隔着结冰的海走不过去。水上那几段画成虚线
- 经过：路线经过的、或者紧挨着路线的城，按先后列出来（起点、终点那块地方上的城不算）
- 量完一条接着等你点下一条，换一条路；不想量了，点顶上那条的「退出」（或按 Esc），路线留着
- 面板上能换走法、换个起点、清掉路线

1.1 新增：坐船；列出沿路经过的城。装着 1.0 的照旧能用，重新装一次就是 1.1。

在地图右下的「工具」里打开。算出来的路线只在用它的时候显示，关掉就没了，世界一个字不变。

用到的能力：

- 看地图：按地形和水陆找路、量距离
- 知道你点了哪里：请你在地图上点起点和终点
- 在地图上加图层和标注：画出路线
- 看历史（可选）：用附近的城给起点、终点起名字，列出沿路经过的城（按历史的最后一年）；不给也能用，改写经纬度，不列城
