# 存进世界的图层(格式第 1 版)

插件算出来的图层可以存进世界:别人打开这个世界**不用装插件**,网站照存下的数据自己画。所以这份格式网站要长期认得:**按第 1 版存下的世界,以后的网站照样打得开、画出来一样**。仓库里有一组第 1 版的样本世界文件([`tests/fixtures/plugin-layers/`](../../tests/fixtures/plugin-layers/))和守着它们的测试([`tests/plugin-layer-format-v1.test.ts`](../../tests/plugin-layer-format-v1.test.ts)):每一格每一年的数和颜色变了,测试就不过。

写插件用不着自己拼这个格式:工具插件交 [`layer.cells`](api.md#图层layercells1layerregions1layermarks1),用的人点「存进这个世界」;推演插件在清单里标 [`sim.layers`](sim.md#图层),推演时网站自己存;地图插件在清单里登记 [`map.layers`](map.md#图层),长地图时网站自己存。这一页给想读写世界文件的人,也说明网站怎么画。

标注图层(线、点、框)不存进世界,不在这一页。

## 两种图层

| | 地块图层 | 按州按年份的图层 |
|---|---|---|
| 一格是 | 一个地块(`unit: "cell"`) | 一个州(`unit: "region"`) |
| 份数 | 一份(也可以带 `years` 存几份,随年份变) | 一定带 `years` |
| 现在谁存 | 工具插件:用的人在图例上点「存进这个世界」,存那一刻的样子;地图插件(开放以后):长地图时网站自己存,跟着地图走,地形改了整批重算换掉 | 推演插件:推演时从第 0 年起每隔 `keep` 年存一份那张表的值;工具插件:交 [`layer.regions`](api.md#图层layercells1layerregions1layermarks1),用的人点「存进这个世界」,存整串 |

**格式不分来源**:哪种插件存的都是同一种块、同一个结构,块里不记是谁存的。工具插件存按州按年份的图层,用的也是这一种,一个字段都不加。要分来源只看同一个文件里有没有 `sim.<插件编号>` 那一块(推演插件推到哪的状态):有,就是推演插件推出来的,**跟着历史走**,换了历史整批换掉;没有,就是工具插件存的。工具插件存的地块图层和历史无关;它存的按州图层是照那段历史算的,历史换了(历史那一块变了)网站就把它从世界里去掉,只改名不算。

## 存在世界文件的哪里

世界文件(`.civworld`)是一个不压缩的 ZIP:清单 `manifest.json` 加 `parts/` 底下的几块,外壳和清单的定义见 [`src/gen/worldFormat.ts`](../../src/gen/worldFormat.ts) 开头。图层单独成块;跟着历史走的还可以放在历史那一块里。两种放法意思一样,网站都认:

**单独一块。** 一个图层一块,清单 `parts` 里那一项:

| 字段 | 值 |
|---|---|
| `name` | `layer.<插件编号>.<图层编号>`,最长 64 个字 |
| `file` | `parts/layer.<插件编号>.<图层编号>.gz`(没压缩的写 `.bin`) |
| `schema` | 格式版本,现在是 `1` |
| `need` | `"extra"`:看世界用不着它也打得开 |
| `by` | 插件编号,和块名里的一样 |
| `zip`、`sum`、`bytes` | 压缩方式(`gzip` 或 `none`)、解压后字节的 SHA-256、解压后的字节数 |

- 插件编号:小写字母开头,只有小写字母、数字,中间可以有单个 `-`,最长 32 个字
- 图层编号:小写字母或数字开头,只有小写字母、数字、`-`,最长 25 个字。工具插件交图层时的 `id` 可以有大写和 `_`、最长 32 个字,不合这一条的存进世界时换成 `h` 加 8 位小写十六进制(`id` 每个字的 UTF-16 编码做 FNV-1a 32 位散列),比如 `Sea_Distance` 存成 `h38a0d7c6`
- 同一个文件里有 `sim.<同一个插件编号>` 那一块的,是跟着历史走的图层(见上面「格式不分来源」)

**在历史那一块里。** 推演插件推出来的图层还可以放在历史(`parts/civ.gz`)的 `simLayers` 里,网站推演完存成文件时就是这样:一个数组,每项是下面「一块里的内容」那个对象再加两个键,`by`(插件编号)、`id`(图层编号),`(by, id)` 不重复。这时文件里没有 `sim.<插件编号>` 那一块,也没有它的图层块。两种放法一个文件里只能用一种。

**上限。** 一块解压后最多 8,000,000 字节;一个世界最多 16 个图层块,历史里的 `simLayers` 最多 16 项。推演插件还有自己的上限(每个插件 4 个图层、`keep` 1–1000 年、一个图层的数最多 6,000,000 字节),推演时就挡下了,见[推演插件 · 上限](sim.md#上限);地图插件每个最多交 4 张,见[地图插件 · 上限](map.md#上限)。

## 一块里的内容

块的字节是 gzip 压缩过的 `CIVSNAP1`:一段 JSON 写结构,数组的原始字节接在后面(小端),编码见 [`src/gen/snapshot.ts`](../../src/gen/snapshot.ts) 开头。解开以后是一个对象,类型是 `worldFormat.ts` 里的 `PluginLayerValue`:

| 键 | 必须 | 规矩 |
|---|---|---|
| `title` | 是 | 图层的名字,最长 40 个字 |
| `unit` | 是 | `"cell"` 一格一个地块,`"region"` 一格一个州 |
| `years` | 否 | 每一份是哪一年的:数的数组,不空,从小到大、不重复,在 0 到 60000 之间;按州的不晚于历史推到的那一年。不给 = 只有一份,哪一年都画它;按州的一定要给 |
| `values` | 是 | `Float32Array`,份数 × 格数,第 k 份接在第 k − 1 份后面。格数:地块图层是地图的地块数,州的图层是历史的州数。`NaN` = 这一格不画;不能有 ±Infinity |
| `ramp` | 二选一 | 渐变:`{ colors, min?, max? }`,2–16 个颜色;`min`、`max` 是有限数,都给时 `min < max` |
| `classes` | 二选一 | 分类:`[{ value, color, label }]`,1–32 类;`value` 是 −2³¹ 到 2³¹ − 1 的整数,不重复;`label` 最长 40 个字 |
| `legend` | 否 | 图例上写的单位或说明,最长 40 个字 |
| `opacity` | 否 | 0–1,不给按 0.65 画 |

- 只能有这几个键(历史里的 `simLayers` 每项多 `by`、`id`),多一个都不认
- `ramp` 和 `classes` 给且只给一个
- 颜色一律小写的 `#rrggbb`
- 字(`title`、`legend`、`label`)存的是网站查过的那一份:去掉制表符以外的控制字符和改书写方向的字(U+202A–U+202E、U+2066–U+2069),换行换成空格。「最长 40 个字」按 UTF-16 算,一个表情算两个
- 按州的图层:州是历史里的州表,地形大事以后才有的州也算在格数里,之前那几份多出来的格子是 `NaN`(推演插件存的从第 0 年起每 `keep` 年一份)
- `values` 是单精度:分类的 `value` 绝对值超过 2²⁴ 的,不一定有格子的数正好等于它

## 怎么画

1. **挑一份。** 看第 y 年时,用 `years` 里不晚于 y 的最后一份;比第一份还早就不画。没有 `years` 的哪一年都画那一份
2. **每一格一个颜色。**
   - 分类:数等于某一类 `value` 的格子涂那一类的颜色,哪一类都不是的不画
   - 渐变:先定范围 [lo, hi]。给了 `min`、`max` 就用给的;没给的那一头按**这个图层所有份**里的有限数定(没给 `min`:lo = 最小的数,只给了 `max` 时再和 `max` 取小;没给 `max`:hi = 最大的数,再和 lo 取大;一个有限数都没有时,最小的数当 0、最大的数当 1)。所以同一个数在哪一年都是同一个颜色。
     t = (数 − lo) ÷ (hi − lo),小于 0 当 0、大于 1 当 1(hi = lo 时 t = 0);几个颜色从 t = 0 到 t = 1 等距排开,t 落在相邻两色之间的按红、绿、蓝各自线性插值,四舍五入到整数
   - `NaN` 不画
3. **透明度。** 涂了的格子不透明度是 `opacity`(不给 0.65)× 255 四舍五入;`opacity` 是 0 的整个图层都不画
4. **盖到地图上。** 地块图层一个地块一个颜色;州的图层每个地块涂它所在的州那一格的颜色,不在州里的地块、州号超出这一份格数的地块不画。半透明盖在底图上,底图照旧能换
5. **图例。** 写 `title`,有 `legend` 时跟在后面;渐变画一条色带,标上 lo 到 hi;分类一类一行,颜色加 `label`

网站画图用的代码在 [`src/render/pluginLayer.ts`](../../src/render/pluginLayer.ts)(`frameAt`、`framePaint`、`cellColors`)。

## 版本

- 单独一块的格式版本是清单里那一项的 `schema`,现在是 `1`;在历史那一块里的跟着历史那一块的版本走
- 这一版定下以后,**第 1 版的文件网站一直认得,画出来不变**
- 要加东西,哪怕只多一个可选的键,也出新的版本:`schema` 加一。旧网站读到比自己新的图层块不解开、不画,另存时原样带着,世界照样打得开(只是在旧网站上不能公开分享);新网站读第 1 版时转成新的结构

## 读的时候哪些不认

网站打开别人给的世界文件时,每个图层都照上面逐项核对。不合格的:

- 单独一块的,本机打开时只跳过这一块(跟着历史的图层有一块不合格,这段历史的图层都不要),世界照常打开
- 在历史那一块里的,不合格就是历史坏了,整个世界打不开
- 传上作品墙的文件,有一块不合格就整个不收
- 跟着历史走的图层只能按州、一定带年份
- 现在的网站只认跟着历史走的按州图层:文件里没有它那个插件的 `sim.<插件编号>` 块的按州图层,当不合格。以后不分来源,工具插件存的按州按年份图层也认(格式就是上面这一种,不改版本)
