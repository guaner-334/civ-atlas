# 插件开发

给会写一点 JavaScript、想给「文明与地图」写插件的人。插件能读地图和历史、算东西,结果交给网站:在侧栏放一张卡片(文字、数字、表格、按钮),在地图上加图层和标注,或者替你改名、加标记、下命令。

> **插件功能还没开放。** 网站上还没有装插件的入口;这份文档照接口第 1 版写,入口开放以后照这里写的用。
> 开放之前接口的细节还可能调整,调整了会改这份文档。

## 插件是什么

一个插件就是一个 `.civplugin` 文件,里面是一份清单、一个 JS 文件、说明和许可证。装上以后:

- **它跑在一个隔开的地方**:网站给每个插件开一个单独的后台线程,线程外面再套一层沙箱。它不能联网,看不到网站的页面、你的 AI 密钥和账号、别的世界,也不能自己改历史。这些不是靠审核,是技术上做不到,见[能力、权限和限制](limits.md)
- **它要什么都得在清单里写明**:读地图、读历史、看你写的东西、加图层……每样叫一个「能力」。装的时候网站把这些翻成大白话列在权限框里,你点了「装上」它才拿得到
- **画东西的是网站**:插件只交数据(每个地块一个数、一串标注、面板上放哪些格子和按钮),长什么样由网站按自己的样式画。所以平面地图、地球、导出图片都自动支持,插件也没法把界面画得像网站自己的提示来骗人
- **网站这边的数据它拿到的都是复制的一份**:插件改了自己手里的数组,世界不变。要改你写的东西(改名、加标记、下命令)只能「提要求」,网站检查过再照办,照办的整批记一步撤销

第一批只开「工具」一种插件(清单里 `role` 写 `tool`):在地图上量一量、算一算,或者加一个图层。

## 十分钟写一个插件

下面写一个「海拔图层」:按海拔给陆地上色。

**1. 建一个文件夹**,比如 `my-elevation/`,放四个文件:

```
my-elevation/
├── plugin.json   清单里你自己写的那几项
├── main.js       插件代码
├── README.md     说明(装的时候给人看)
└── LICENSE       许可证全文
```

**2. 写 `plugin.json`:**

```json
{
  "id": "my-elevation",
  "name": "海拔图层",
  "version": "1.0.0",
  "role": "tool",
  "api": 1,
  "runtime": "worker",
  "requires": ["world.read@1", "layer.cells@1"],
  "why": { "world.read@1": "要读每个地块的海拔" },
  "description": "按海拔给陆地上色。",
  "license": "MIT",
  "author": { "name": "你的名字" }
}
```

每个字段的意思见[插件包](package.md)。`requires` 里只写用得到的能力:权限框上会一条条列给装的人看。

**3. 写 `main.js`:**

```js
(async () => {
  const world = await civAtlas.world.info();
  const { elevation, water } = await civAtlas.world.cells({ fields: ['elevation', 'water'] });

  // 每个地块交一个数;水上交 NaN,不画
  const values = new Float32Array(world.cells);
  for (let i = 0; i < world.cells; i++) values[i] = water[i] === 0 ? elevation[i] : NaN;

  await civAtlas.layer.cells({
    id: 'elevation',
    title: '海拔',
    values,
    ramp: { colors: ['#1a9850', '#fee08b', '#d73027', '#ffffff'], min: 0, max: 4000 },
    legend: '米',
  });
})();
```

插件拿到的全局对象叫 `civAtlas`,每个调用都返回 Promise。调用名、参数、返回什么见[接口参考](api.md)。

**4. 写 `README.md` 和 `LICENSE`。** README 当纯文字显示,写清插件做什么、为什么要那些能力;LICENSE 放许可证全文(见[许可证](package.md#许可证))。

**5. 打包。** 需要这个仓库的代码和 Node 22 以上:

```bash
pnpm install
npx tsx scripts/pack-plugin.ts path/to/my-elevation     # 写出 path/to/my-elevation/my-elevation.civplugin
```

打包时照网站读插件的规矩核对一遍,哪里不对会直接说。打出来的文件就是插件本身,别拆开重新压缩:网站认插件靠整个文件的指纹。

**6. 装来试**,见下一节。

### 编辑器提示

接口的类型定义在 [`src/plugin/types.ts`](../../src/plugin/types.ts)。在这个仓库里打开 `examples/plugins/` 下的文件,编辑器(VS Code 等)会照 [`examples/plugins/tsconfig.json`](../../examples/plugins/tsconfig.json) 和 [`civ-atlas.d.ts`](../../examples/plugins/civ-atlas.d.ts) 给出 `civAtlas` 的补全和类型检查。在别处写插件,把这两个文件和 `types.ts` 拷过去、改一下里面的路径就行。

## 装来试

入口开放以后:

1. 地图上打开「更多」菜单 →「插件」,打开插件页
2. 点「从文件装…」,选你打出来的 `.civplugin`
3. 网站先检查文件(坏了、要新版网站的会直接说哪里不对),再弹权限框:插件要的每样能力一行,下面是你在清单 `why` 里写的理由
4. 点「装上」。自己打的插件没在作品墙上审过,权限框上会多一条醒目的提示,按钮是「仍然装上」

装好以后:

- 工具在地图右下的「工具」里(手机在右上那一竖排),点一下开始用
- 插件交来的图层在图层面板的「插件图层」里开关
- 插件装在这个浏览器里,所有世界都能用;不自动更新,改了代码重新打包、再从文件装一次就换成新的

插件页里的「开发者模式」(改完代码点「重新载入」、看 `civAtlas.log` 写的日志)还在做。

## 常见问题

**插件能联网吗?能调用 AI 吗?**
不能。插件所在的沙箱技术上连不了任何网址,网站的 AI 也不给插件用,不会花任何人的额度。

**插件算出来的东西存在哪?**
工具算的结果(面板、图层)只在用它的时候显示,关掉就没了,世界一个字节不变。要长期留下,可以用 `store.local`(插件自己的设置,不在世界里)、`store.world`(存进这个世界,存了以后世界不能公开分享),或者提要求让网站改「你写的东西」(加个标记、改个名字,和你自己改的一样能分享、能撤销)。

**我的插件改坏了别人的世界怎么办?**
插件改你写的东西都要经过 `author.apply`:网站只检查改完的世界还能存、能打开,不替用的人判断改得对不对;照办的整批记一步撤销,用的人点「撤销」就回去了。

**别人没装我的插件,打开用过它的世界会怎样?**
只看不存的工具不进世界,对别人没有影响。插件提要求改的名字、加的标记、下的命令进了用的人自己的修改,没装插件也照样在。

**插件能改地形、改推演规则吗?**
第一批不能。
