# 能力、权限和限制

## 能力和权限框

插件要什么都写在清单的 `requires`(和 `optional`)里,每样叫一个能力。装的时候网站把能力翻成大白话列在权限框上,一行一条,下面是作者在 `why` 里写的理由。能力表在 [`src/plugin/pluginCaps.ts`](../../src/plugin/pluginCaps.ts)。这一页讲工具插件的 11 样;推演插件另有 7 样(`sim.` 开头,只给推演插件),权限框上两行,见[推演插件](sim.md#能力和权限框)。工具插件的:

| 能力 | 能用的调用和事件 | 权限框上那一行 |
|---|---|---|
| `world.read@1` | `world.*` | 看地图（地形、气候、河流） |
| `history.read@1` | `history.*` | 看历史（国家、城市、人物、编年史） |
| `author.read@1` | `author.marks`、`names`、`characters`、`interventions`、`notes` | **看你写的东西（笔记、标记、AI 写的正文）**,显眼 |
| `author.write@1` | `author.apply` | **会改你写的东西（改国名人名、加标记和批注、下命令）**,显眼;下面网站固定写一行「改了顶上会说一声，能撤销；下了命令，那一年往后的历史重新推演」 |
| `view.read@1` | `view.get`,事件 `view.year`、`view.select` | 知道你在看哪一年、点了哪里（只在用它的时候） |
| `input.pick@1` | `pick.cell`、`pick.cells`、`pick.box` | 同上一行 |
| `ui.panel@1` | `panel.set`、`panel.clear`,事件 `panel.action` | 不单列(哪个插件都能有) |
| `layer.cells@1` | `layer.cells`、`layer.remove` | 在地图上加图层和标注 |
| `layer.marks@1` | `layer.marks`、`layer.remove` | 同上一行 |
| `store.local@1` | `store.local.*` | 不单列 |
| `store.world@1` | `store.world.*` | 在世界里存自己的数据;下面网站固定写一行「存了以后那个世界不能公开分享，能存成文件发给别人。每个世界第一次存的时候还会问你」 |

`host.info`、`log` 不要能力。几样能力归同一行的只列一行;各行的先后照上表,和清单里写的先后无关。作者在 `why` 里写的理由排在网站那行小字下面。权限框最底下固定一行:

> 它不能联网、看不到你的 AI 密钥和账号、看不到别的世界、改不了历史。

要了 `author.write@1` 的插件下的命令会让历史重新推演,这一行换成:

> 它不能联网、看不到你的 AI 密钥和账号、看不到别的世界、改不了地形和推演规则。

权限框上的字以网站上显示的为准。

**只要用得到的。** 每多一样能力,权限框上就多一行,装的人就多一分犹豫。用得上但不是非要不可的放进 `optional`:用的人可以不给,插件用 `host.info()` 的 `caps` 看给没给,没给就少做一点(示例「量路程」没给「看历史」时改写经纬度)。

## 插件做不到的事

工具插件跑在网站页面里一个隔开的小框里,框里再开一个后台线程,插件代码在线程里(推演插件跑在 QuickJS 里,能用的更少,见[推演插件](sim.md#quickjs-里没有什么))。这几件事技术上做不到,不靠审核:

- **联网**:`fetch`、`XMLHttpRequest`、`WebSocket`、`EventSource`、`importScripts`、`import()`、`navigator.sendBeacon`、WebRTC 都连不出去,也加载不了任何网址上的字体、图片、脚本
- **动态执行代码**:`eval`、`new Function`、`setTimeout` 传字符串都被拦下;要用的库直接写进 `main.js`
- **碰网站的东西**:没有 `document`,看不到网站的页面;读不到网站的 `localStorage`、IndexedDB、cookie(AI 密钥、账号、存着的别的世界都在那里面)。插件自己要存东西用 `store.local`、`store.world`
- **另开线程**:`Worker` 拿不到
- **和别的插件说话**:每个插件各在各的框里,互相听不见
- **自己改世界**:拿到的数据都是复制的一份;改你写的东西只能通过 `author.apply` 提要求,网站检查过再照办,整批能撤销。改地形、改推演规则第一批不开
- **用网站的 AI**:插件调不了 AI,不花任何人的额度

插件能拿到的,就是[接口参考](api.md)里那些调用交出来的数据。

## 上限

插件包本身的上限见[插件包](package.md#文件里有什么),每个调用的上限在[接口参考](api.md)里各自那一节;推演插件的上限(用时、内存、表、图层、命令、编年史……)见[推演插件](sim.md#上限)。工具插件的汇总:

| 项目 | 上限 | 超了 |
|---|---|---|
| 插件文件 | 2 MB;`main.js` 1 MB,README、LICENSE、清单、图标各 64 KB | 装不上 |
| `world.cells` 一次 | 16 种 | `limit` |
| `history.people`、`history.events` 一页 | 2000 条 | `limit` |
| `author.notes` 一页 | 100 篇 | `limit` |
| `author.apply` | 一次 200 条,一秒 10 次;改完以后一共最多 20000 个改名、10000 条命令,存档要存得下 | `limit` / `busy` |
| 标记 | 一个世界 2000 个,所有标记一共圈 10000 个州 | `limit` |
| 一个标记 | 圈 500 个州;名字 40 个字,说明 2000 个字 | `limit` |
| 改名 | 一个名字 16 个字 | `limit` |
| 点选的提示 | 40 个字 | `limit` |
| 面板 | 2000 个格子、4000 个字;表格 500 行 × 20 列;套 4 层 | `limit` |
| 地块图层 | 一个插件 4 个;渐变 2–16 色,分类 1–32 类 | `limit` / `bad-args` |
| 标注图层 | 一个插件 4 个;每个 5000 项、地块和点一共 200000 个;字 40 个 | `limit` |
| `store.local` / `store.world` | 64 KB / 1 MB;最多套 32 层 | `limit` |
| 日志 | 一条 2000 个字 | 只记前 2000 个字,末尾标出截掉了 |
| 同时没回的调用 | 16 个 | `busy` |
| 网站递给插件的数据 | 每秒 64 MB | `busy` |

## 插件什么时候会被停掉

下面这些情况网站直接停掉插件:拿掉它的小框和线程,它交的面板、图层一起拿掉。插件卡里写明为什么停了(出错的写上插件报的那句错),用的人可以点「再试一次」。

| 情况 | 说明 |
|---|---|
| 开得太慢 | 插件代码顶层 10 秒内没跑完(比如顶层写了死循环) |
| 出错 | 抛出没接住的错,包括事件回调里抛的。`await` 的调用出错只是那一次拒绝,不会停 |
| 发话太多 | 一秒里发给网站的话超过 200 条(每次调用、每条日志都算一条) |
| 一条话太大 | 一次发给网站的东西超过约 4 MB(字按一个字两个字节算) |
| 没反应 | 网站每隔两秒问插件线程一声,5 秒内回不了(在跑很长的同步计算、死循环) |
| 乱发话 | 绕开 `civAtlas` 直接 `postMessage` 了网站不认得的东西,或者冒充网站的回话 |

**算得久的要分段。** 插件线程在跑同步计算时回不了网站的话。几万个地块算一遍通常不到一秒;要算更久的,每算一段 `await` 一下,让线程空出来:

```js
for (let i = 0; i < n; i++) {
  heavy(i);
  if (i % 5000 === 0) await new Promise((r) => setTimeout(r, 0));
}
```

## 写插件时照着查

这几条写插件时自己对一遍;作品墙收插件以后,审核也看这些:

- 做的和清单、README 里说的一致,`why` 写清每样能力拿来干什么
- 能力没多要:清单里要的,代码里都用得到
- 面板上的字不冒充网站:不请用的人输入密钥、密码、账号,不仿网站自己的提示
- 字合规,不显示不合适的内容
- 代码是人能读的,不压缩、不混淆;没有 `eval`、联网、动态加载这类写法(反正跑不起来)
- 同一个世界、同样的操作,算出来的东西一样:不按日期、随机数偷偷变样
- 许可证写对了,`LICENSE` 里是全文

审核时网站还会在种子 7、2024 的示例世界(默认参数,看的是最后一年)上把插件跑一遍,用的是和从文件装上一样的沙箱,截下地图(带插件的图层)和面板:

- 请用的人点一处:第一次给那一年人口最多的城,第二次给和它在同一块陆地上(走陆路连得到)人口最多的另一座城(那块陆地上没有别的城时给人口第二多的城),再请点就当用的人不点了(`cancelled`);框一片:第一次给地块最多的那一国的外接框
- 改你写的东西(`author.apply`)一律不照办,回 `blocked`
- 安静半秒、线程空着就算跑完;20 秒还没停下来就停掉
- 上作品墙以后,种子 7 那张地图截图就是插件卡的封面

推演插件(`role: "sim"`)换一种跑法:两个种子各推 3000 年,官方一遍、带插件一遍,和官方比现存国家、仗、灭国、分裂、改朝换代、瘟疫、人口;
再带插件推到 1500 年存成世界文件、读回来另装一份插件接着推到 3000 年,要和一口气推的一模一样(插件把东西记在全局变量里、不放进小本子 `note`,这里就对不上)。
截下带插件推到最后一年的地图(盖着它的第一个图层),交上插件写的编年史前 20 句。推不下去、分段推对不上都算没过;两个种子一共最多 3 分钟。
